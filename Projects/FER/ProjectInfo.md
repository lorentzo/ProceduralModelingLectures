## Project design document: details

Students can choose between signing up for existing project design document OR writing custom project design document.

### Existing project design document

Link: https://github.com/lorentzo/ProceduralModelingLectures/blob/main/Projects/FER/ProjectDesignDocumentDefault.md

### Writing custom project design document

One-page free-form project design document describing what will be created.
It is not required to describe technical details, rather conceptual idea and general roadmap of 
development: what will be developed and in which order. 

Requirements for project design document:
* Project roadmap must contain 3 milestones.
* Should contain inspiration images/videos.
* Procedural modeling techniques must be used.
* Resulting model/artefact in each milestone must be parametric. At least 3 parameters.

One Page Design Philosophy: https://www.youtube.com/watch?v=E9_wLks1kAg.

For inspiration, see following links:
* https://github.com/lorentzo/ProceduralModelingLectures/blob/main/Projects/FER/ProjectDesignDocumentDefault.md

## Project submission: details

Submission of all three milestones are required.

Each milestone submission must contain at least:
* Source project file containing parametric model/artefact created in current milestone (e.g., .HIP/.HIPNC/.BLEND)
* At least 3 renders or viewport screenshots showing different instances of parametric model/artefact created in current milestone.
* One page document discussing workflow, concepts implementation, result, etc.

Create public GitHub repository. Store each milestone in separate folder. Send repository link to lovro.bosnar@fer.hr.

NOTE: same source project file can be used for all milestones, but make sure to freeze and version 
source project files for each milestone submission. Example of source project files submission names:
1. ProjectName_NameSurname_m1
2. ProjectName_NameSurname_m2
3. ProjectName_NameSurname_m3
